Embedded Systems & Polar Instrumentation

Autonomous Sea-Ice Vertical Temperature & Conductive Heat Flux Profiler

STM32F411 (Black Pill) 1-Wire DS18B20 Chain Fourier Heat Flux Watchdog (IWDG) Brown-Out Reset (BOR)
Situation

Monitoring Antarctic sea-ice melt requires continuous vertical thermal profiling in the Marginal Ice Zone, where freezing temperatures often cause system lockups and data corruption.

Task

Developed firmware on an STM32 microcontroller to acquire multi-depth temperatures, calculate conductive heat flux, and ensure autonomous system recovery.

Action

Sampled a 6-node DS18B20 1-Wire string and calculated Fourier heat flux. I implemented moving-average filtering, error-masking for faulty data, and register polling to audit hardware resets.

Result

Achieved temperature accuracy within 0.1 degrees Celsius, validated data streaming to telemetry, and confirmed efficient low-power operation.

Digital Logic & Hardware Acceleration

CORDIC Coordinate Rotation Unit Co-Processor for StarCore-1 RISC CPU

Verilog HDL RISC Architecture Fixed-Point Shift-and-Add Icarus Verilog & GTKWave
Situation

The 16-bit StarCore-1 RISC CPU lacked native trigonometric hardware, making it difficult to perform fast coordinate transforms for robotic applications.

Task

Designed, synthesized, and verified a 16-iteration CORDIC co-processor in Verilog HDL to accelerate sine and cosine calculations directly in hardware.

Action

I implemented a 4-state state machine using shift-and-add arithmetic and an arctangent lookup table. I also extended the CPU control unit with custom opcodes, pipeline stall logic, and a write-back multiplexer.

Result

The co-processor computes trigonometric outputs in 19 clock cycles at 100 MHz. It achieves high precision while using only about 150 logic cells on the FPGA.

Robust Digital Cascade Controller for Multi-Configuration DC Servo Motor

MATLAB / Simulink Quantitative Feedback Theory (QFT) Cascade Architecture System Identification
Situation

Speed and position control of a DC servo motor was hindered by static dead-bands, digital-to-analog converter saturation, and varying inertial loads across four different system configurations.

Task

Performed system identification and synthesized a robust digital cascade controller that meets strict bounds for settling time and overshoot.

Action

I derived plant transfer functions using least-squares regression. Then, I performed loop shaping on the inner speed controller and outer position compensator while tuning hardware parameters to eliminate actuator saturation.

Result

Verified robust setpoint tracking and disturbance rejection across all plant configurations in both Simulink and physical laboratory testing.
